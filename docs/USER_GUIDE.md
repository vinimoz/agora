# Agora – User Guide

## 🌟 Welcome to Agora

Agora is a participatory democracy platform that allows communities, organizations, and institutions to **discuss, propose, and decide together**.

It provides structured tools to paticipate to any configured inquiries. U can participate, with comments, with supports, create your own inquiries.
The Options tools, let your organize debates, build laws and documents,reach consensus, manage decisions transparently, manage your options with Kanban, Timline, etc.

> **Philosophy:** Transparent, structured, and inclusive collaboration.

---

## 🧠 Core Concepts

Understanding these 3 elements is essential:

---

### 🔍 Inquiry (Main Object)

An **Inquiry** is the central element of Agora.

It represents any topic or process:

| Inquiry Type | Purpose | Example |
|--------------|---------|---------|
| **Petition** | Gather citizen support | "Plant 1000 trees in the city" |
| **Proposal** | Introduce new ideas | "Create a community garden" |
| **Debate** | Structured discussion | "Should we ban single-use plastics?" |
| **Consultation** | Public feedback collection | "New park design preferences" |
| **Law Proposal** | Legislative drafting | "Amendment to housing law" |
| **Service Request** | Administrative assistance | "Request for childcare support" |

👉 Think of it as:
> **A container for a democratic process**

---

### 🗂️ Inquiry Groups (Organization Layer)

**Inquiry Groups** are used to organize multiple inquiries into structured views.

They:
- Group related inquiries
- Provide navigation and hierarchy
- Improve readability for complex processes

#### Examples:

| Group Type | Use Case | Example |
|------------|----------|---------|
| **Assembly** | Citizen gatherings | Town hall meetings |
| **Referendum** | Binding votes | Constitutional referendum |
| **Program** | Multi-phase projects | 5-year urban plan |
| **Working Group** | Focused committees | Environmental task force |

👉 Think of it as:
> **Folders + structured navigation for inquiries**

---

### 🧩 Options (Building Blocks)

**Options are structured contributions inside an Inquiry.**

They are more powerful than comments.

| Option Type | Description | Visual Icon |
|-------------|-------------|-------------|
| `argument_for` | Supporting arguments | 👍 |
| `argument_against` | Opposing viewpoints | 👎 |
| `amendment` | Proposed modifications | ✏️ |
| `chapter` | Document sections | 📑 |
| `poll_option` | Selectable choices | 📊 |
| `official_summary` | Final conclusions | ✅ |

👉 Think of them as:
> **Tools used to build the content of an inquiry**

## 🎨 Layout & Interaction Modes

Agora uses different **visual modes (families)** depending on the goal.

---

### 💬 Debate

Used for **discussion and deliberation**.

Includes:
- Positions (for / against)
- Arguments
- Alternatives

👉 Goal: explore ideas and viewpoints

---

### 🤝 Consensus

Used to **resolve disagreements and reach agreement**.

Includes:
- Objections (blocking)
- Exceptions (non-blocking)
- Resolution tracking

👉 Goal: converge toward a shared decision

---

### 📋 Kanban

Used for **workflow management**.

- Options appear as cards
- Columns represent statuses

👉 Goal: organize tasks and processes visually

---

### 📅 Timeline

Used for **time-based processes**.

- Events
- Milestones
- Deadlines

👉 Goal: visualize chronological progression

---

### 🗳️ Vote (Beta)

Used for **decision-making**.

- Structured voting systems
- Multiple voting methods

👉 Goal: formalize decisions

---

### 📜 Structure (Experimental)

Used for **writing structured documents or laws**.

Includes:
- Chapters
- Sections
- Articles
- Amendments

👉 Goal: build formal texts collaboratively

## 🚀 Getting Started

### Step 1: Access Agora
- Open Nextcloud and click the **Agora** app icon from the menu

### Step 2: Create Your First Inquiry

1. Click **"New Inquiry"** button
2. Choose your **role/group** (User, Official, etc.)
3. Fill in the required fields:
   - **Title** – Clear, concise headline
   - **Description** – Detailed explanation
   - **Category** – Thematic classification
   - **Location** – Geographic scope
4. **Optional**: Add attachments and cover image
5. Click **"Publish"**

> 💡 **Tip**: If moderation is enabled, your inquiry will appear in the "To Moderate" menu until approved.

### Step 3: Engage with the Community

- 💬 **Comment** on inquiries
- 👍 **Support** proposals you agree with
- 🔄 **Create child inquiries** (if permitted)
- 📎 **Share resources** – files, polls, collectives, etc.

## 🎯 Practical Examples

### Example 1: Citizen Petition

**Role**: Regular User

1. Create a **Petition** inquiry: "Install bike lanes on Main Street"
2. Add location: "Downtown district"
3. Category: "Transport & Mobility"
4. Collect **supports** from neighbors
5. After reaching threshold, an **Official** responds

### Example 2: Legislative Amendment

**Role**: Legislative Group Member

1. Create **Law Proposal** inquiry
2. Structure with **chapters** and **articles**
3. Receive **amendments** from citizens
4. Facilitate **debate** on controversial articles
5. Publish **official_summary** with final text

### Example 3: Community Consultation

**Role**: Collective Group Member

1. Create **Consultation** inquiry
2. Add **consultation_questions** as options
3. Collect public feedback
4. Analyze responses in **official_result**

## 👥 User Roles & Permissions

Agora uses **six specialized groups** to manage access and responsibilities:

| Group | Capabilities | Badge |
|-------|--------------|-------|
| `Agora Users` | Create inquiries, support, comment | 👤 |
| `Agora Moderator` | Approve/reject content, archive | 🛡️ |
| `Agora Official` | Post official responses, bypass moderation | 👔 |
| `Agora Legislative` | Manage law-related content | ⚖️ |
| `Agora Editor Group` | Group inquiry management | 📋 |

> **Note**: You must belong to `Agora Users` to see attached files and inquiry covers.

## 🔧 Moderation System (For Moderators)

When moderation is **enabled**, all content requires review:

### Moderator Dashboard

| Section | Content |
|---------|---------|
| 📥 **To Moderate** | Pending approvals |
| ✅ **Approved** | Publicly visible |
| ❌ **Rejected** | Not published |
| 📦 **Archived** | Closed processes |

### Moderation Actions

| Action | Effect |
|--------|--------|
| **Approve** | Makes content public |
| **Reject** | Returns to creator with feedback |
| **Archive** | Closes but preserves history |
| **Delete** | Removes permanently |

## ❓ Frequently Asked Questions

### Q: What's the difference between an Inquiry and an Option?

**A:** An Inquiry is a container (like a petition or debate). Options are the building blocks inside it (arguments, amendments, chapters).

### Q: Can I edit my inquiry after publishing?

**A:** Yes, but edits may go back to moderation depending on settings.

### Q: How do I know if my inquiry is approved?

**A:** You'll receive a notification. You can also check the "To Moderate" menu.

### Q: What voting methods are available?

**A:** Simple majority, Majority Judgement (beneficial/number), Condorcet, Approval, and Nauru methods.

### Q: Can I create an inquiry group?

**A:** Yes, if you have the `Agora Editor Group` role.
